# OpenSlack demos

This directory contains repeatable product demonstrations. Demo data is evidence-scoped: a fixture
proves a local contract, while live GitHub evidence is recorded only after the corresponding
external operation succeeds.

## AI organization commercial loop

The [AI organization commercial-loop demo](ai-organization-commercial-loop.md) presents a fixed
90-day manufacturing pilot through:

- one six-phase JavaScript Workflow Runtime module;
- six governed agent roles;
- seven deterministic Markdown artifacts;
- a fixture rehearsal with no network activity;
- an optional live rehearsal using GitHub App task authorship and governed draft-PR delivery.

Start with the [scenario](ai-organization/scenario.md), then follow the
[runbook](ai-organization/runbook.md) and
[rehearsal checklist](ai-organization/rehearsal-checklist.md).

The checked-in recorded run is a presentation backstop. It is `LOCAL_PASS` evidence, not proof that
Qoder, a model provider, GitHub delivery, human approval, or production notification delivery is
currently configured.
