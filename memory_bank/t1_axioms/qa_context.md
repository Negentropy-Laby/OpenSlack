# QA Context

Test existence is not release evidence. Each gate records the exact command,
scope, revision, and result. Local checks, authenticated qualification,
clean-machine capstones, hosted CI, release, and live observations are reported
independently.

Documentation validation covers schemas, authority uniqueness, generated byte
consistency, links and anchors, migration completeness, and state-promotion
evidence.

Notification Delivery additionally requires Go build/vet/race validation,
contract and integration tests against real PostgreSQL, migration checks,
Prometheus rule validation, Compose validation, service documentation
verification, and an exact workspace-manifest hash check. Its historical gate
and review outcomes are indexed in root T3; mutable machine receipts remain
under `services/notification-delivery/docs/testing/`.
