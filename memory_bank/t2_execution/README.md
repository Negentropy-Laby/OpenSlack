# Execution Control

`memory_bank/control-plane.json#/assignments` records planned ownership and
reconciled execution state. It is updated only through reviewed pull requests
after the referenced GitHub/OpenSlack evidence has been checked.

The four canonical execution standards in this flat directory govern approval
language, documentation changes, implementation preferences, and
requirements-to-evidence traceability. They derive executable rules from T0-T1
context without creating another standards authority or nested standards
directory.

`current_roadmap.md` is generated. Actual claim refs, executing agents, pull
requests, reviews, and merge outcomes remain authoritative in GitHub/OpenSlack.
