# 制造企业 90 天 AI 转型试点执行摘要

组织：华东精密制造有限公司

目标：在 90 天内证明一个可审计、可回滚的 AI 试点能够降低质量异常处置周期。

## 选择

首个试点聚焦“质量异常处置 Copilot”。它只读取 MES/QMS 的受控快照，帮助班组长汇总证据、定位责任人与生成下一步建议，不直接写入生产系统。

## 成功边界

- 周期目标从配置基线 12 小时降至 4 小时。
- 95% 的结论具备来源引用。
- 未经授权的 GitHub 审批和直接 main 写入必须保持为零。
- 所有经济价值先标记为 `configured_estimate`，取得试点观测后才能升级为 `observed`。

## 治理

Qoder/OpenSlack 的确认不等于 GitHub Approval。正式采纳仍由独立人类 GitHub 身份完成 Review。
