# 90 天实施计划

| 天数 | 交付物                          | 负责人           | 验收                                       |
| ---- | ------------------------------- | ---------------- | ------------------------------------------ |
| 15   | 流程与数据范围基线              | 业务与数据负责人 | 范围、证据源和退出条件完成签认             |
| 30   | 只读试点数据集与真实周期基线    | 数据团队         | 缺陷编码映射和基线样本通过复核             |
| 60   | 质量异常处置 Copilot 受控试运行 | 试点产品负责人   | 无直接生产写入且证据引用率达到目标         |
| 90   | 价值、风险与扩展决策包          | 试点治理委员会   | 依据 observed 指标作出继续、调整或停止决定 |

## 回滚触发条件

- 出现未经授权的数据写入。
- 关键证据无法追溯。
- 连续两个复盘周期未改善处置周期。
